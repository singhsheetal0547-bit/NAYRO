# NAYRO PERMISSION & PRIVACY POLICY MANUAL

## 1. Declared System Permissions

NAYRO requires the following permissions declared in `AndroidManifest.xml`:

| Permission String | Permission Category | Technical Rationale | Approval Flow |
| :--- | :--- | :--- | :--- |
| `android.permission.INTERNET` | Install-time Normal | Cloud communication with Google Gemini API endpoint. | Auto-granted on install |
| `android.permission.RECORD_AUDIO` | Runtime Dangerous | Microphone access for local wake-word framing and speech recognition. | Compose Runtime Launcher Prompt |
| `android.permission.POST_NOTIFICATIONS` | Runtime Dangerous | Display persistent background service status and reminder notifications. | Compose Runtime Launcher Prompt |
| `android.permission.FOREGROUND_SERVICE` | Install-time Normal | Permits foreground service lifecycle management for background execution. | Auto-granted on install |
| `android.permission.FOREGROUND_SERVICE_MICROPHONE` | Install-time Normal | Declares background audio processing capability under Android 14+. | Auto-granted on install |
| `android.permission.SYSTEM_ALERT_WINDOW` | Special Permission | Displays the floating assistant overlay bubble over other applications. | Redirect to System Overlay Settings |
| `BIND_ACCESSIBILITY_SERVICE` | Special Permission | Grants `NayroAccessibilityService` access to read screen nodes and perform clicks. | Redirect to Accessibility Settings |
| `RECEIVE_BOOT_COMPLETED` | Install-time Normal | Allows NAYRO to recover incomplete tasks and restore background state on reboot. | Auto-granted on install |
| `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` | Special Permission | Prevents OS Doze mode from killing background wake word listening on OEM skins. | Redirect to Battery Settings |

---

## 2. Privacy & Data Handling Principles
1. **Local-First Audio Processing**: Microphone audio during standby is processed locally on-device by `LocalWakeWordEngine`. Audio frames are never uploaded to the cloud.
2. **KeyStore Encryption**: User API keys are stored in encrypted `SharedPreferences` encrypted with AES-256 GCM master keys generated by Android KeyStore.
3. **Opt-In Personal Memory**: Data stored in Room database (`local_memory`, `personal_notes`) remains 100% on-device and can be edited or deleted by the user at any time in Settings.
